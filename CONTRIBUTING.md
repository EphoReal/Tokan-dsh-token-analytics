# Contributing to Tokan — DSH Token Analytics

Thank you for your interest in contributing to Tokan!

## How to Contribute

### Reporting Bugs

1. Check if the bug has already been reported in [Issues](https://github.com/fthuu/Tokan-dsh-token-analytics/issues)
2. If not, create a new issue with:
   - Clear title and description
   - Steps to reproduce
   - Expected behavior
   - Actual behavior
   - Environment details (OS, Node.js version, DSH version)

### Suggesting Features

1. Check [Issues](https://github.com/fthuu/Tokan-dsh-token-analytics/issues) for existing feature requests
2. Create a new issue with the `enhancement` label
3. Describe the feature and its use case

### Pull Requests

1. Fork the repository
2. Create a feature branch:
   ```bash
   git checkout -b feature/amazing-feature
   ```
3. Make your changes
4. Run tests:
   ```bash
   node test-waste-v33.js
   node test-waste-v8.js
   node test-tokenizer-attribution.js
   ```
5. Commit your changes:
   ```bash
   git commit -m 'Add amazing feature'
   ```
6. Push to the branch:
   ```bash
   git push origin feature/amazing-feature
   ```
7. Open a Pull Request

### Code Style

- Use ES modules (`import`/`export`)
- Follow existing code patterns
- Add comments for complex logic
- Keep functions focused and small

### Testing

- Add tests for new features
- Ensure all tests pass
- Include edge cases

## Development Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/fthuu/Tokan-dsh-token-analytics.git
   cd Tokan-dsh-token-analytics
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run tests:
   ```bash
   node test-waste-v33.js
   node test-waste-v8.js
   node test-tokenizer-attribution.js
   ```

## Questions?

Feel free to ask in [Discussions](https://github.com/fthuu/Tokan-dsh-token-analytics/discussions).
